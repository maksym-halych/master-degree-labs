# NULP Coursework

Workspace for NULP coursework — lecture artifacts, lab source and lab reports, plus the tooling that produces them.

## Deadlines

Lab deadlines and their status are tracked in Linear, in the [master-degree-labs](https://linear.app/maksym-24/project/master-degree-labs-a6052c1c9e11) project. Each issue carries the subject's key from [docs/SUBJECTS.md](docs/SUBJECTS.md) as a label and the deadline as its due date.
