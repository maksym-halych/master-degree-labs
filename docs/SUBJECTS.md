# Subjects

Every subject has a short Latin key. Agent docs, commit scopes, Python names and any other place that needs a Latin name use the key, never the Cyrillic folder name. Keys are unique across all semesters. A new subject gets its row here before anything refers to it.

A key has three characters:

1. The first letter of the subject's topic in English, given in the key explanation.
2. The first letter of the lecturer's surname, transliterated to Latin.
3. The semester number.

The work unit column gives the name of a subject's numbered assignments, which commit scopes append to the key: `ad1-lab2`, `ri1-practice1`. A subject without work units is referred to by its key alone.
